# Security Policy

## Supported versions

Security fixes are provided for the latest minor release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting feature.
Include a minimal reproduction, affected versions, and potential impact. Remove
tokens, private video, OAuth files, and personal information from all reports.

## Publishing safety

VideoForge never publishes by default. A config must enable publishing **and** the
CLI must receive `--approve-publish`. Keep OAuth material outside the repository,
use least-privilege platform accounts, and start with private/unlisted visibility.
